# Roadmap v2.3

## Features maiores
- Download paralelo de playlists (threading por faixa)
- Cookies via arquivo `.txt` em vez de só browser
- Renomear arquivo antes de salvar
- Download de canal do YouTube inteiro
- Auto-retry configurável em caso de falha

## Refatorações
- Quebrar `main.py` em arquivos menores — já tem ~1200 linhas
- `load_config()` chamado dentro de loops de render — cache com TTL curto
- Validação de chaves no `import_config` para evitar injeção de paths

## Qualidade
- Mais testes unitários cobrindo downloader e i18n
- Teste de integração do update checker
